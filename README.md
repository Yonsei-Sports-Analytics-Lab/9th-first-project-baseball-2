# ⚾ 추가 연구: 타석 결과 및 타구 질에 따른 구종 사용 변화

기존 연구에서는 투수가 장타(XBH)를 허용한 이후, 해당 장타를 허용한 구종의 사용률이
동일 타자와의 다음 재대결에서 어떻게 변화하는지를 분석하였다.

추가 연구에서는 분석 범위를 확장하여 다음과 같은 질문을 확인하고자 한다.

1. 장타 허용 이후의 구종 사용 변화는 해당 타자와의 재대결 이전,
   **바로 다음 타자를 상대하는 타석에서도 나타나는가?**
2. 이러한 구종 사용 변화는 단순한 타석 결과뿐만 아니라
   **허용한 타구의 질(xwOBA)과도 관련이 있는가?**
3. 타구 질에 따른 구종 사용 변화가 **직후 타석과 동일 타자와의 재대결에서
   서로 다르게 나타나는가?**

이를 위해 타석 결과와 xwOBA를 기준으로 직후 타석 및 재대결에서의
구종 사용 변화를 비교하고, 최종적으로 회귀분석을 통해 이들의 관계를 확인하였다.


---

## 1. 장타 허용 직후 타석에서의 구종 사용 변화

### 연구 목적

기존 분석에서는 장타를 허용한 투수가 동일 타자를 다시 상대했을 때
장타를 허용한 구종의 사용을 줄이는 경향이 있는지를 분석하였다.

이번 분석에서는 이러한 변화가 동일 타자와의 재대결까지 기다리지 않고,
**장타 허용 직후 상대하는 다음 타자에게도 즉각적으로 나타나는지**를 확인한다.

또한 장타(XBH) 이후의 변화만을 독립적으로 살펴보는 대신,
**Out, Single, XBH** 이후의 구종 사용 변화를 비교한다.

이를 통해 장타 허용 이후 나타나는 구종 사용 변화가
일반적인 타석 종료 이후의 변화와 비교했을 때 상대적으로 강하게 나타나는지를 확인한다.


### 분석 방법

각 타석의 결과를 다음 세 집단으로 구분하였다.

- Out
- Single
- XBH

각 이벤트가 발생한 구종을 기준으로,
해당 투수가 **바로 다음 타자를 상대하는 타석에서 그 구종의 사용률을 얼마나 변화시켰는지** 측정하였다.

## 2. 타구 질에 따른 직후 타석에서의 구종 사용 변화

### 연구 목적

1번 분석에서는 타석의 결과를 기준으로 이후 구종 사용 변화를 비교하였다.

하지만 동일한 타석 결과가 발생하더라도 실제 타구의 질에는 차이가 존재할 수 있다.
예를 들어 같은 아웃이라도 약한 타구와 강한 타구는 투수에게 서로 다른 정보를 제공할 수 있다.

따라서 이번 분석에서는 단순한 타석 결과를 넘어,
**타구의 질이 직후 타석에서의 구종 사용 변화와 어떠한 관계를 가지는지** 확인한다.


### 분석 방법

타석 결과를 다음 네 가지 유형으로 구분하였다.

- Out
- Single
- Double
- Home Run

각 결과 내에서 **xwOBA를 타구 질을 나타내는 지표로 사용**하고,
xwOBA의 변화에 따라 해당 구종의 직후 타석 사용 변화가 어떻게 나타나는지를 분석하였다.

이를 통해 동일한 결과 내에서도 더 높은 타구 질을 허용한 경우,
이후 해당 구종의 사용 변화가 더 크게 나타나는지를 확인한다.

## 3. 타구 질에 따른 재대결에서의 구종 사용 변화

### 연구 목적

2번 분석에서는 타구 질에 따른 구종 사용 변화가
**바로 다음 타자를 상대하는 타석**에서 나타나는지를 확인하였다.

이번 분석에서는 이를 동일 투수-타자 간 재대결까지 확장한다.

즉, 특정 타자가 한 구종을 상대로 만들어낸 타구의 질이
투수가 **해당 타자를 다시 상대했을 때의 구종 선택과도 관련되는지** 확인한다.

이를 통해 타구 질에 따른 구종 사용 변화가 단기적인 다음 타석에서만 나타나는지,
혹은 동일 타자와의 재대결에서도 관찰되는지를 비교할 수 있다.


### 분석 방법

2번과 동일하게 타석 결과를 다음 네 가지 유형으로 구분하였다.

- Out
- Single
- Double
- Home Run

각 결과에서 이전 맞대결의 **xwOBA와 해당 구종의 재대결 사용 변화** 사이의 관계를 분석하였다.

재대결은 **동일 시즌 내 동일 투수-타자 간 다음 맞대결**로 정의하였다.

## 4. 회귀분석

앞선 분석에서 관찰한 패턴을 종합적으로 확인하기 위해 회귀분석을 실시하였다.

단순히 결과별 평균이나 xwOBA와의 개별적인 관계를 비교하는 것을 넘어,
**타석 결과와 타구 질을 동시에 고려했을 때에도 구종 사용 변화와의 관계가 나타나는지** 확인하는 것을 목적으로 한다.


### 4.1 직후 타석에서의 회귀분석

직후 타석에서의 구종 사용 변화를 종속변수로 설정하고,
이전 타석의 결과와 xwOBA를 설명변수로 사용하였다.

또한 **타석 결과 × xwOBA interaction term**을 포함하여,
xwOBA와 구종 사용 변화 사이의 관계가 타석 결과에 따라 다르게 나타나는지를 확인하였다.

이를 통해 Out을 기준으로 Single, Double, Home Run 등의 결과에서
타구 질에 따른 구종 사용 변화가 어떻게 달라지는지를 분석한다.

> **회귀분석 결과 및 해석**
<img width="775" height="32" alt="image" src="https://github.com/user-attachments/assets/3a80ac3c-0f23-44dd-8548-3c1265d6e85c" />
종속변수(change) : 직후 타석 구종 사용률 - season baseline
기준 : out event

| 변수      | 계수    | p-value | 의미                         |
| Intercept | +0.0143 | <.001   | Out이고 xwOBA=0일 때 +1.43%p |
| Single    | -0.0103 | <.001   | Out보다 약 1.03%p 더 감소    |
| XBH       | -0.0561 | <.001   | Out보다 약 5.61%p 더 감소    |
| xwOBA     | -0.0241 | <.001   | Out에서 xwOBA가 1 증가할 때 2.41%p 추가 감소 |
| Single × xwOBA |-0.0254 | <.001 | Single에서는 xwOBA 효과가 Out보다 2.54%p 더 음(-)의 방향|
| XBH × xwOBA | +0.0045 | .135 | XBH에서는 xwOBA 효과가 Out과 유의하게 다르다고 보기 어려움 |

타석 결과 자체의 효과: XBH(장타)가 가장 큰 구종 사용 감소와 관련됐다(-5.61%p).
타구 질(xwOBA)의 관계 : Out에서 음의 방향으로 나타났으며, Single에서는 이 관계가 Out보다 유의하게 더 강했다.
(out, single event에서는 타구 질이 좋을수록 다음 타석에서 그 구종 사용을 줄이는 경향이 존재)
반면 XBH에서는 xwOBA와 구종 사용 변화의 관계가 Out과 유의하게 다르지 않았다.
(장타에서는 타구 질에 따른 구종 사용 변화의 관계가 유의하게 발견되지 않음)
R² = 0.009 -> 이 변수들이 전체 구종 변화의 변동을 많이 설명하는 모델은 아님

### 4.2 재대결에서의 회귀분석

동일한 회귀분석을 동일 투수-타자 간 재대결을 대상으로 실시하였다.

이를 통해 타석 결과와 타구 질에 따른 구종 사용 변화가
직후 타석뿐만 아니라 **동일 타자와의 다음 맞대결에서도 나타나는지** 확인한다.

직후 타석과 재대결의 회귀분석 결과를 비교함으로써,
관찰된 구종 사용 변화가 단기적인 반응에 가까운지,
혹은 특정 타자와의 이후 맞대결에서도 지속적으로 나타나는지를 살펴본다.

> **회귀분석 결과 및 해석**

| 변수      | 계수    | p-value | 해석 |
| Intercept | +0.0606 | <.001   | Out, xwOBA=0일 때 baseline 대비 +6.06%p |
| Single    | -0.0232 | <.001   | Out보다 2.32%p 낮음 |
| XBH       | -0.1052 | <.001   | Out보다 10.52%p 낮음 |
| xwOBA     | -0.0914 | <.001   | Out에서 xwOBA 1 증가 시 9.14%p 감소 |
| Single × xwOBA | -0.0146 | .002 | Single의 xwOBA 기울기가 Out보다 1.46%p 더 음(-)  |
| XBH × xwOBA    | +0.0438 | <.001 | XBH의 xwOBA 기울기가 Out보다  4.38%p 덜 음(-) |

XBH라는 결과 자체의 차이는 강하지만, XBH 내부의 타구 질이 높아질수록 회피가 더 강해진다는 단순한 관계는 관찰되지 않았다.
R²: 직후 타석 0.009 → 재대결 0.030으로 상승--> 설명력 자체는 여전히 낮지만, 재대결 모델에서 상대적으로 더 많은 변동을 설명하고 있다

## 연구 질문 정리

본 추가 연구는 궁극적으로 다음 질문을 다룬다.

> **투수의 이후 구종 선택 변화는 단순히 이전 타석의 결과와 관련되는가,
> 아니면 실제 허용한 타구의 질까지 반영하여 나타나는가?**

또한 이러한 변화가 장타 직후의 다음 타석과
동일 타자와의 재대결에서 어떻게 다르게 나타나는지를 비교함으로써,
이전 타석의 결과 및 타구 질과 이후 구종 선택 사이의 관계를 보다 구체적으로 분석한다.
