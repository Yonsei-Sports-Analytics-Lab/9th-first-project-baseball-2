# 🧾 Report (최종 정리 재현 단계)

`main.py`가 순서대로 부르는 단계별 코드입니다. 각 단계는 `docs/최종정리.md`의 한 부분을 다시 계산해 표를 돌려주고, `main.py`가 이를 `data/processed/final/`에 저장한 뒤 보고서 수치와 비교합니다.

| 파일 | 단계 | 최종 정리 |
|---|---|---|
| `data.py` | 분석 표본 CSV 로드, 상황 변수 추가 | p.2 |
| `avoidance.py` | ① 회피 확인: 사다리(M0–M3) 순수 감소·오즈비, 타자 맞춤 회피, 다시 던질 때의 실행 비교 | p.3–5 |
| `factors.py` | ② 회피 요인: 결과 × 타구 질, 구종 사용 변화 GBM + SHAP | p.6–7 |
| `effect.py` | ③ 회피 효과 평가: GBM 선택점수, 구사율 상호작용과 재검증, 전체 과정 부트스트랩 (R `lme4` 필요) | p.8–10 |
| `cases.py` | ④ 사례: 회피율 상·하위 투수, 시즌 안정성 | p.11 |
| `reference.py` | 보고서에 실린 수치와 재현 수치 대조표 | 전체 |
