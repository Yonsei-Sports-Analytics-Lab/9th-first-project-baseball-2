## src/ — 분석 코드

### src/collection/ — 데이터 수집

| 파일 | 역할 |
|---|---|
| `statcast_scraper.py` | Statcast를 월 단위로 수집해 `data/raw/{연도}/{월}.parquet`에 저장. ⚠️ 고정 데이터 원칙상 실행하지 않음 |

### src/preprocessing/ — 전처리

| 파일 | 역할 |
|---|---|
| `load_raw_pitches.py` | 수집한 월별 parquet을 모두 읽어 하나로 합침 |
| `research_sample.py` | 팀 research CSV에 있는 행만 남김(키: `game_pk`, `at_bat_number`, `pitch_number`, `pitcher`). CSV 파일명 검사 |
| `pitch_family.py` | `pitch_type` 코드 → fastball / breaking / offspeed 분류 |
| `pitch_type_distribution.py` | 구종·구종계열 빈도 리포트 |
| `build_next_ab_dataset.py` | 장타(또는 대조군 이벤트) → 다음 타석의 구종 재사용 이벤트 데이터셋 생성. 다음 타자 / 같은 타자 재대결 두 모드 |
| `data_pipeline.py` | 위 단계를 한 번에 실행(로드 → 분포 리포트 → 이벤트 데이터셋) |

### src/analysis/ — 분석

공용 모듈:

| 파일 | 역할 |
|---|---|
| `avoidance_stats.py` | 회피 검정용 통계 함수(baseline 대비 변화, 층화추출 대조군, diff-in-diff, 매칭) |
| `mixed_effects_model.py` | 혼합효과 로지스틱 회귀용 데이터 구성, 공식, ICC·보정표·투수별 기울기 순위 |
| `glmer_runner.py` | R `lme4::glmer`를 rpy2로 호출해 적합·결과 추출 (R 필요) |
| `intensive_margin.py` | 같은 구종을 다시 던졌을 때 코스·무브먼트·구속 편차 계산 |
| `situation_matching.py` | 상황 매칭 사다리(M0~M3): 상황 변수, 단계별 `field_out` 대조군 추출, SMD 균형표, 순수 감소, 층화. 재대결·다음 타자 두 모드 지원 (노트북 01의 정의를 옮김) |
| `hit_quality.py` | 타구 질 분석: 모든 타구 이벤트의 회피 지표를 한 번에 계산, 배럴 판정, xwOBA 분위, 약한 아웃 대비 칸별 비교 |

실행 스크립트 (`python -m src.analysis.<이름>`):

| 파일 | 분석 | 역할 |
|---|---|---|
| `run_same_batter_rematch_analysis.py` | 메인 | 같은 타자 재대결: baseline 2종 → 대조군 넷팅 → 재사용률 → 혼합모델 → 동타/이타 → 투수 단위 매칭 |
| `run_intensive_margin_analysis.py` | 메인 | 재대결에서 다시 던진 구종의 실행 변화 |
| `run_pitch_type_avoidance_analysis.py` | 메인 | 장타 맞은 구종별 회피 강도(혼합모델) |
| `run_pitch_type_reuse_rate_analysis.py` | 메인 | 구종별 재구사율 감소 요약 |
| `run_outcome_anchor_check.py` | 진단 | 대조군(`field_out`) 뒤 사용 비중이 왜 늘어나는지 결과별로 확인 |
| `run_pitch_avoidance_analysis.py` | 보조 | 다음 타자 기준 회피(경기 내 baseline → 시즌 baseline → diff-in-diff) |
| `run_mixed_effects_model.py` | 보조 | 다음 타자 기준 혼합효과 로지스틱 회귀 |
| `run_mixed_effects_model_comparison.py` | 보조 | 위 모델의 원본 공식 vs 단순화 공식 비교(robustness) |
